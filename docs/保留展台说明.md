# 勇气进化 · 六阶段动作工坊

双击 **勇气进化.html** 即可使用。脚本、模型、贴图和参考图片全部内嵌，不需要账号、付费服务或网络连接。

主线形态：**黑球兽 → 滚球兽 → 亚古兽 → 暴龙兽 → 机械暴龙兽 → 战斗暴龙兽**。

本地修订 **13** 完善六个形态的招式演出：每次进场完成后自动展示一次，也可点击“释放 · 招式名”或按 **F** 单独重放。动作包含蓄力、释放、余波与收势；特效与动作共用时钟，暂停、重放和切换形态会同步处理。连续观看会等当前形态的大招播完、回到待机后再进入下一阶段。

本次加强火球的高温亮芯、翻卷尾焰、火星和爆散余烟；双弹使用连续推进烟迹与先后爆破；盖亚能量炮增加流动表面、汇聚光流、投出拖尾和扩散冲击波。泡泡大小不一，带虹彩薄膜与破裂水珠。粒子批量绘制并循环复用，支持离线播放和两种材质风格。

战斗暴龙兽使用错步屈膝、双爪一前一后备战，加入胸部呼吸、肩臂随动、小幅观察和脚步承重；登场使用落地缓冲、短暂停顿、抬头戒备。龙爪挥击加入腰胸转动，展盾动作收成防守姿势。修订 13 的盖亚能量炮举臂阶段让前臂和掌甲一起向内旋转，双掌相对，双手留出托抱能量球的空间，再连续过渡到向前投出。镜头适当退开以容纳能量球。

沿用修订 11 的暴龙兽与机械暴龙兽细节：暴龙兽保留已加长的前后肢，掌部略缩小、前臂增厚，双臂和爪尖稍向内收，使腕掌比例更紧凑；机械暴龙兽肉体前肢加长、加粗，机械肩臂略放低，肘部外展、前臂保持伸出，三根金属爪的末端向掌内弯曲。爪根和腕甲保持衔接，弯曲形状也包含在 GLB 模型中。弯尾带有侧弯、上扬及末端跟随，双脚前后错步、膝盖略向外打开。机械暴龙兽保持平顺的胸背连线及伸出的头颈。低吼时会出现跟随嘴部、向外扩散的气浪，支持暂停和旋转观察。修订前后侧面对照保存在 `预览/龙型体态对照.png`。

本版沿用亚古兽已确认版本的游戏模型修整路线。亚古兽保留 Motion 4 的网格、蒙皮权重和全部六段动作；另外五个形态使用同一来源的模型，分别进行表面细化、材质设置及动作编排。它们属于游戏模型适配，并非 1999 年动画的逐细节 1:1 复刻。

## 使用

- 底部选择形态，或点击“进化至下一形态”。每个形态都有“进场 → 招式展示 → 待机”的完整流程。
- “连续观看进化”从黑球兽开始，依次播放至战斗暴龙兽；再次点击可停止连续观看。
- 拖动旋转，滚轮或双指缩放；顶部切换正面、侧面、背面和立体视角。
- 切换“动画原色 / 哑光手办”。可暂停动作，或打开线框检查模型。
- 点击角色可触发回应。下方按钮触发该形态的专属动作；绿色“释放”按钮可随时重放招式。选择其他动作会取消当前招式及特效。
- 滚球兽、亚古兽、暴龙兽、机械暴龙兽支持嘴巴张合滑块。黑球兽和战斗暴龙兽没有外露的可动嘴部，不显示该滑块。
- “下载当前动画模型”导出当前形态、当前材质的 GLB。
- 键盘数字 1–6 选择形态，左右箭头切换形态，空格暂停或继续，F 释放招式。

## 动作

| 形态 | 制作重点 |
| --- | --- |
| 黑球兽 | 呼吸、眨眼、短耳回应、轻弹起落与落地压缩 |
| 滚球兽 | 上颌开合、触角根部与中段、末端的延迟跟随、弹跳 |
| 亚古兽 | 保留 Motion 4：略微打开肩臂、掌心朝前招手、腿部主导的踏步 |
| 暴龙兽 | 前臂饱满、手掌紧凑，双爪略收、高低错位，屈膝错步；弯尾随动、低吼伴随气浪 |
| 机械暴龙兽 | 机械肩臂略放低、肘部外展，三枚金属爪尖向掌内弯曲，腕爪连贯；肉体前肢加长，后腿错步承重；弯尾随动、展翼低吼及气浪 |
| 战斗暴龙兽 | 非对称备战、脚步承重、落地缓冲、腰胸带动挥爪、展盾戒备、双臂聚能投射 |

每个 GLB 含 **Idle、Wave、Roar、Step、Entrance、Nod、Special** 七段骨骼动画。Special 是该形态的大招身体动作。亚古兽原有六段动画和几何保持不变，仅在六形态查看器增加第七段；单体版保持 Motion 4。通用英文名称对应各形态自己的动作；例如幼年期的 Step 为弹跳，战斗暴龙兽的 Wave 为龙爪挥击，Roar 为展盾戒备。

查看器中的眨眼使用原素材的睁眼 / 闭眼贴图切换；眨眼、低吼气浪、招式粒子、泡泡、火球、导弹、能量球、舞台光环和界面转场不包含在 GLB 骨骼动画中。要观看完整特效，请打开完整离线 HTML；无需联网加载。GLB 默认采用各形态的待机姿势，包含修订后的肢体姿态和尾部曲线。

## 招式

| 形态 | 招式 | 本地演出 |
| --- | --- | --- |
| 黑球兽 | 酸性泡泡 | 鼓气、泡泡从面部向前飘散、逐渐破裂 |
| 滚球兽 | 泡泡 | 张嘴吐出较大的泡泡，触角随身体轻摆 |
| 亚古兽 | 小型火焰 | 吸气、张嘴、喷出小火球及火焰尾迹、后坐回稳 |
| 暴龙兽 | 超级火焰 | 屈膝蓄力、张嘴发射更大的火球、冲击圈和火星 |
| 机械暴龙兽 | 究极破坏炮 | 胸口发射口显露、双弹先后离膛、推进尾迹及爆散 |
| 战斗暴龙兽 | 盖亚能量炮 | 双掌相对举臂托抱、流光汇集为能量球、向前投射、冲击波和余辉 |

动作与特效为本次手工编排的即时 3D 演出，没有使用原动画片段。机械暴龙兽原网格没有可独立开合的胸甲骨骼，目前使用附着胸部的发射口显露过渡。黑球兽没有独立嘴部骨骼，使用身体鼓气和面部发射点表现吐泡泡。
