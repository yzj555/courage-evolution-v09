# 勇气的进化 · 场景演出修订 09

这是基于已确认的修订 13 模型制作的独立进化演出。本版对照初代片段重新编排画面，并将进化、大招与自然待机接在同一条时间线上。

## 打开与操作

- 本地预览：http://127.0.0.1:4173/cinema.html?v=9
- 离线使用：解压后用 Edge / Chrome 直接打开 cinema.html。模型、贴图、程序均内嵌，不需要账号、付费服务或联网加载。
- 播放 / 暂停、重播、拖动进度、0.5 / 1 / 1.5 倍速、全屏、五段连播。
- 每段进化结束后自动释放目标形态的大招，收势后保留轻微呼吸、头部和肢体动作。
- 点击“释放大招”可重放当前形态的技能。空格播放暂停，R 重播，F 释放大招；输入控件聚焦时保留控件原有键盘操作。
- 始终使用自由视角：鼠标或手指拖动旋转，滚轮或双指缩放，播放和暂停时都可操作。“重置视角”恢复当前片段的默认角度、观察中心和缩放，不改变播放进度。
- 已移除导演模式与自动运镜。播放、重播、拖动进度、释放大招和调整窗口尺寸都保留用户视角；首次进入或切换片段时设置可容纳进化形态的默认全景。更改窗口尺寸后，可按“重置视角”重新适配。
- “音效”开启本地合成的进化、蓄力、发射与冲击声，默认关闭。
- 右上角“返回保留版”打开已确认的修订 13 模型展台。

## 勇气徽章与进化共鸣

勇气徽章依照东映初代设定图重建：上部收窄的金色吊牌、穿绳孔与白绳、中间横向梯形橙色纹章片、双圆环与八枚分离三角光芒组成的太阳纹样，以及下部刻纹、斜齿和倒角厚度。框体、嵌片、吊环和绳索都是本地三维几何。

超进化与跃迁进化使用独立的徽章镜头：0–0.5 秒完整亮相并收住轻微摆动，0.5–1.7 秒太阳刻纹由暗到亮，1.7–2.5 秒暖色光芒增强；2.5 秒在光幕最亮处切换为神圣计划，随后 2.25 秒完成外壳由白转橙、短促振动、屏幕响应和向上发射数据条。徽章与数码器互斥显示，光芒始终跟随纹章中心。整段共鸣为 4.75 秒，后续通道、变形和大招的动作速度保持不变。

共鸣段按道具设定和原作的触发关系重新编排；现有短片未覆盖完整的徽章激活镜头，因此不宣称与某一集逐帧一致。普通进化继续使用修订 07 的 2 秒数码器开场。

## 数码器与数据通道

普通进化的数码器完整展示为 1.15 秒，随后用 0.85 秒推进屏幕。屏幕点亮、共鸣光圈和音效随节奏同步。完整外壳仍保留在画面内，窄屏也留出播放控制栏的空间。

神圣计划按初代画面重做了宽肩收腰的外壳、顶部短天线、上方一枚和下方两枚蓝色圆按键、侧面开关、圆形文字圈与方形绿色屏幕。外壳有倒角和厚度，按键与天线使用立体结构。

数据条由同一组实例从屏幕内部连续上行，越过屏幕上沿后朝上射出，屏幕内外共用位置、间距与运动相位。镜头随后跟随光条进入上方的数据通道，通道里的白色条带继续向上流动。没有另画一套屏幕条纹与射出条带叠加。

修订 07 中，神圣计划在发射前完成回正，收住左右偏移、侧倾和偏航；发射期间光条中轴与通道中轴都位于画面正中，每根横条保持水平。屏幕内、射出段和通道段共用淡绿白色光条材质与辉光强度，避免亮色屏幕上的叠加发光将射出条带冲成纯白。首尾仍保留渐入渐出。

通道文字依据官方日文数码文字对照表重绘，使用 47 个基础字符和“デ／ジ”两个浊音字形，替换旧版随机几何线段；按原片通道采用镂空轮廓、灰绿色描边、沿环周转向的排列，并减少密度。数码器的文字圈使用两次“デジタルモンスター”。字形为本地矢量重绘，通道字符排列是本项目编排，未宣称逐字逐帧复刻原片。

修订 05 加宽的喇叭口继续保留。通道只有向上俯仰，没有左右偏移或侧倾，白色数据条始终水平、中心位于同一直线上。三条使用通道的路线各延长 0.65 秒：普通进化通道为 2.025 秒，超进化为 2.275 秒，跃迁进化为 2.650 秒。保持逐步加速，但整体穿行放慢；后续变形与大招只顺延开始时间，动作速度不变。

## 镜头衔接

演出将数码器 / 徽章、数据通道和角色显现分成独立的镜头区间，关键交接处用短暂光幕衔接。前后实体角色也不再同时交叉淡入淡出。

载入遮罩内提前准备皮肤顶点、材质、线框和技能效果，避免在徽章切到角色时才首次编译与上传。相机由用户自由控制，演出时间线不再控制相机位置或朝向。大招从亮相末尾衔接，释放后保留自然待机；主动暂停则冻结动画，仍可调整视角。
